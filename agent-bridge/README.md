# agent-bridge

Мост между Claude Code на компьютере и приложением Claude Buddy на телефоне (протокол v1, совместимый с coucou: TLS с закреплённым сертификатом, JSON по строкам). Запросы разрешений Claude Code приходят на телефон, ответ Allow/Deny возвращается в Claude. Node >= 18, нужен системный `openssl`, npm-зависимостей нет. Части кода адаптированы из coucou (MIT).

## Запуск

```sh
node bridge.mjs                  # слушает первый частный IPv4 (192.168.x, 10.x, 172.16-31.x), порт 47821
node bridge.mjs --host 192.168.1.20 --port 47821 --name "Мой Mac"
```

В терминале появится ссылка `coucou://pair?...`. Вставьте её в приложении (раздел «Агенты») или откройте на телефоне. Ссылку с токеном никому не показывайте.

Файлы лежат в `~/.claude-buddy/`: `cert.pem` и `key.pem` (создаются один раз, ключ с правами 0600), `pairing.json` (токен, 0600), `hook.sock` (сокет для хуков, 0600). Переменная `CLAUDE_BUDDY_DIR` меняет папку.

- `--new-pairing` выпускает новый токен (старый телефон перестаёт подходить).
- `--revoke` удаляет токен. Работающий bridge сразу отказывает любому `hello`.
- Одновременно подключён один телефон; второй получает `error busy`.

## Хуки Claude Code

```sh
node install-hooks.mjs            # только показывает diff для ~/.claude/settings.json
node install-hooks.mjs --yes      # применяет: сначала копия settings.json.bak-ГГГГММДД-ЧЧММСС
node install-hooks.mjs --uninstall --yes
```

Скрипт добавляет только записи, команда которых указывает на наш `hook.mjs` (события SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, PermissionRequest, Notification, Stop, StopFailure, SessionEnd), чужие хуки не трогает. Если JSON повреждён, файл не меняется. Diff строится от переформатированного JSON, при записи файл форматируется с отступом 2.

## Поведение и безопасность

- TLS-сервер привязан только к выбранному LAN-адресу. Токен: 32 случайных символа, сравнение через `timingSafeEqual`. `hello` ждём 10 с, строка больше 64 КиБ закрывает соединение, неизвестные сообщения игнорируются.
- `hook.mjs` никогда не блокирует Claude Code. Если bridge не запущен, телефона нет или решение не пришло за 110 с, он завершается с кодом 0 без вывода, и Claude показывает обычный запрос. Bridge сам ничего не разрешает.
- Телефону уходит команда до 500 символов; длиннее обрезается, добавляется `truncated: true`, а `allow` для такого запроса игнорируется (работает только `deny`). Для файловых инструментов отправляется только имя файла. Промпты, вывод и содержимое файлов не отправляются, токен и команды не пишутся в лог.
- Отпечаток запроса: SHA-256 (hex) от `pillId, sessionId, tool, command, inputKey`, склеенных через U+001F; `inputKey` случайный на каждый запрос.
- Решение принимается, только если отпечаток совпадает с ещё ожидающим запросом. Через 115 с запрос снимается.

## Тесты

```sh
node --test
```
Фальшивый телефон (`lib/fake-phone.mjs`) делает TLS-рукопожатие с проверкой отпечатка сертификата, hello/welcome, получает сессии и approval и отвечает decision.
